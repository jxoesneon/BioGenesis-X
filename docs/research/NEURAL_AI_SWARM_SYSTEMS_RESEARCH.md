## 1. Hive-Mind Swarm Coordination

### 1.1 3D Reynolds Boids & Biological Space Swarms

Standard 2D flocking algorithms fail in 3D biopunk void environments where Void-Fauna organisms (such as Abyssal Swarmers, Caudal Hunters, and Spore Drones) navigate 6-DOF space around massive living capital ships. We extend Craig Reynolds’ classic model into a 3D bio-fluidic flocking solver with 5 primary force vectors:

$$\mathbf{F}_{\text{total}} = w_s \mathbf{F}_{\text{separation}} + w_a \mathbf{F}_{\text{alignment}} + w_c \mathbf{F}_{\text{cohesion}} + w_o \mathbf{F}_{\text{obstacle}} + w_t \mathbf{F}_{\text{target}} + w_b \mathbf{F}_{\text{bio-turbulence}}$$

```
                      [Target Seeking Vector Ft]
                                 ▲
                                 │
     [Cohesion Fc] ──►   ( Void-Fauna ) ◄── [Alignment Fa]
                            ▲    ▲
                            │    │
      [Separation Fs] ──────┘    └────── [Obstacle Avoidance Fo (Hull SDF)]
```

#### Mathematical Formulations

1. **Separation ($\mathbf{F}_s$)**: Prevents soft-body collision between swarm organisms using an inverse-square repulsion field:
   $$\mathbf{F}_s = \sum_{j \in N_i, j \neq i} \frac{\mathbf{p}_i - \mathbf{p}_j}{\|\mathbf{p}_i - \mathbf{p}_j\|^3} \cdot \left( r_{\text{clearance}} - \|\mathbf{p}_i - \mathbf{p}_j\| \right)$$

2. **Alignment ($\mathbf{F}_a$)**: Matches velocity vectors with local hive neighbors, modified by organ efficiency $\eta_{\text{neural}}$:
   $$\mathbf{F}_a = \left( \frac{1}{|N_i|} \sum_{j \in N_i} \mathbf{v}_j - \mathbf{v}_i \right) \cdot \eta_{\text{neural}}$$

3. **Cohesion ($\mathbf{F}_c$)**: Pulls organisms toward the local center of mass of the swarmlet:
   $$\mathbf{F}_c = \left( \frac{1}{|N_i|} \sum_{j \in N_i} \mathbf{p}_j \right) - \mathbf{p}_i - \mathbf{v}_i$$

4. **Obstacle Avoidance ($\mathbf{F}_o$)**: Employs Analytic Signed Distance Fields (SDF) of player and capital ship hulls (`buildHullSDF`) to generate gradient repulsion before visual clipping occurs:
   $$\mathbf{F}_o = -\nabla \text{SDF}(\mathbf{p}_i) \cdot \exp\left( -\alpha \cdot \text{SDF}(\mathbf{p}_i) \right)$$

5. **Bio-Turbulence ($\mathbf{F}_b$)**: Adds organic wave movement generated by Simplex 3D noise (`noise.ts`), simulating thruster plume agitation and bio-fluid pulse wake:
   $$\mathbf{F}_b = \mathbf{n}_{\text{simplex3D}}(\mathbf{p}_i \cdot k_{\text{freq}} + t \cdot \omega_{\text{pulse}})$$

### 1.2 Spatial Acceleration: 3D Spatial Hash Grid ($O(N)$ Neighbor Queries)

To achieve 60 FPS performance in Three.js with $N = 2,000+$ active organisms, linear $O(N^2)$ neighbor evaluation is replaced by a high-performance **3D Spatial Hash Grid**.

```
Spatial Hash Key Formulation:
key = (floor(x / cell_size) * 73856093) ^ 
      (floor(y / cell_size) * 19349663) ^ 
      (floor(z / cell_size) * 83492791) (mod HashSize)
```

| Structure | Query Complexity | Memory Footprint | Rebuild Cost | Dynamic Units |
|---|---|---|---|---|
| Naive Distance Matrix | $O(N^2)$ | $O(N^2)$ | $O(0)$ | Poor |
| 3D Octree | $O(N \log N)$ | $O(N \log N)$ | $O(N \log N)$ | Moderate |
| **3D Spatial Hash Grid** | **$O(N)$ expected** | **$O(N + \text{Cells})$** | **$O(N)$ flat array** | **Ideal for WebGL/Workers** |

## 2. Utility AI & Goal-Oriented Action Planning (GOAP)

### 2.1 Utility AI Scoring Curves for Biological Drives

Each Void-Fauna organism evaluates internal physiological drives using continuous mathematical response curves. Utility values range from $0.0$ to $1.0$.

```
Utility Scores:
 1.0 ┼                                      ─── U_threat (Exponential)
     │                                    ──
     │                                ───
 0.5 ┼ ─────────── U_hunger (Sigmoid)
     │        ───
 0.0 ┼─────────┴─────────────────────────────────────────► Drive Parameter x
```

#### Mathematical Drive Equations

1. **Biomass Hunger ($U_{\text{hunger}}$)** — Logistic Sigmoid:
   $$U_{\text{hunger}}(x) = \frac{1}{1 + e^{-k_{\text{h}}(x - x_{\text{half}})}}, \quad k_{\text{h}} = 8.0, \; x_{\text{half}} = 0.40 \text{ (Biomass Reserve)}$$

2. **Hemolymph Hydraulic Pressure ($U_{\text{pressure}}$)** — Linear Clamp:
   $$U_{\text{pressure}}(P) = 1.0 - \text{clamp}\left(\frac{P - P_{\text{min}}}{P_{\text{max}} - P_{\text{min}}}, 0.0, 1.0\right)$$

3. **Threat Assessment ($U_{\text{threat}}$)** — Quadratic Exponential Curve:
   $$U_{\text{threat}}(D, \mathbf{V}) = \text{clamp}\left( \left(\frac{R_{\text{detect}} - D}{R_{\text{detect}}}\right)^2 \cdot \left(1.0 + \frac{\mathbf{V}_{\text{player}} \cdot \hat{\mathbf{r}}}{v_{\text{max}}}\right), 0.0, 1.0 \right)$$

4. **Bio-Plasma Reservoir Charge ($U_{\text{plasma}}$)** — Logarithmic Curve:
   $$U_{\text{plasma}}(C) = \frac{\ln(1.0 + 9.0 \cdot C)}{\ln(10.0)}$$

### 2.4 Organ Damage Modulation of Utility Scoring & Preconditions

Because Void-Fauna are living ships built from modular organ systems, destruction of specific internal organs dynamically rewires their AI state space:

```
[Organ Damage Detected: Plasma Gland Destroyed]
               │
               ├─► Set Action Precondition: PlasmaGlandIntact = FALSE
               ├─► Zero Utility Weight: W_plasma = 0.0
               └─► Recalculate Drive Weights: W_threat *= 2.5, W_flee *= 3.0
```

- **Plasma Gland Destroyed**: Ranged bio-spit actions become impossible; AI converts instantly to close-range suicidal ramming or flee/regeneration mode.
- **Neural Ganglion Severed**: Local synaptic latency increases by $+500\text{ms}$; Boids flocking alignment weight drops to $0.0$ (unit acts erratically).
- **Spiracle Gill Vent Clogged**: Bio-fluid temperature spikes; unit enters emergency heat-venting state, forcing it to open hull plates and reveal soft vulnerable internal core tissue.

### 3.1 3D Volumetric Navmesh & Corridor Spatial Graph

Interior boarding actions occur inside organic, pulsing vascular tunnels, thoracic habitat chambers, and sphincter doorways. Standard planar 2D navmeshes cannot accommodate 6-DOF wall-crawling organisms, biological fluid currents, and shifting ceiling heights.

```

                  │   R_tunnel = 4.2m, FlowVec = (0, 0, 0.5)
                  ▼
       [Node 2: Vascular Valve] ◄─── Sphincter Doorway (State: Open/Pulsing)
                  │   R_tunnel = 2.8m, WallSurface = Chitin Ribs
                  ▼
       [Node 3: Thoracic Cavity] ─── Spatial Cover Nodes (Soft Mucus / Ribs)
```

### 3.2 Dynamic Line-of-Sight & Biological Soft Cover

Internal combat introduces **soft biological cover** that degrades as it absorbs fire:

```
[Player FPS Raycast] ───► [Mucus Sack Cover (Occlusion: 0.85)] ───► [AI Defender]
                                      │
                                  Absorbs 150 Damage
                                      │
                                      ▼
                        [Cover Ruptures / Acid Burst!]
```

- **Raycast/SDF Occlusion**: Cover evaluation calculates both geometric line-of-sight and density-based ray attenuation:
  $$I_{\text{vis}} = I_0 \cdot \prod_{k \in \text{Obstacles}} (1.0 - \text{occlusionFactor}_k)$$
- **Dynamic Flanking Generation**: Boarding AI units calculate flank vectors by projecting orthogonal paths along the vascular tunnel normal:
  $$\mathbf{P}_{\text{flank}} = \mathbf{P}_{\text{target}} + \mathbf{R}_{\text{tunnel}} \cdot \left(\cos\phi \cdot \mathbf{u}_{\text{wall}} + \sin\phi \cdot \mathbf{v}_{\text{wall}}\right)$$
